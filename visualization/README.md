# Beta-density crossings

Extract the explorer ZIP and open index.html locally. Change the number of other observations. Drag sideways or focus the diagram and use the arrow keys to rotate the plot. The two highlighted curves are densities for counts 2 and 0; their lower envelope is the thick mint curve. Its peak is the intersection, and the dotted line is the binary baseline 3/4.

With zero other observations the curves cross at 1/2 exactly at the baseline. With seven other observations they cross at 1/7 with height 10(6/7)^9. The moving trial point is 3/(2(t+1)), where t is the full observation count. Values are rounded for display.

Use Python 3.11 or newer and Pillow 10.1 or newer. Run python3 visualization/render.py from the repository root to rebuild the looping GIF and the offline ZIP.
