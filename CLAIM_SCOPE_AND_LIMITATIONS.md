# Scope and limitations

The beta shapes are induced by uniform-prior Bernoulli updates with integer counts a>b≥0 and f≥0 other observations. Sharpness of the factor 1 is over all such counts, with equality exactly at f=0. The stopping consequence concerns the original PPR-1v1 and PPR-1vr rules with the same error parameter and original thresholds.

The replay tests finite families. External peer review, formal verification and an exhaustive priority search remain pending.
